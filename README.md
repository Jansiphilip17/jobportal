# JobPortal – Django Job Portal

A full-featured Naukri-like job portal built with Django, Bootstrap 5, and PostgreSQL/MySQL.

## Features
- Candidate & Recruiter registration/login
- Job posting, search, and filtering
- One-click job apply with resume upload
- Application tracking (pipeline stages)
- Interview scheduling with candidate notification
- Recruiter dashboard with applicant management
- Notifications system
- Company profiles
- REST API with JWT auth
- Admin panel

## Tech Stack
- **Backend:** Django 4.2, Django REST Framework
- **Database:** PostgreSQL (Render) / MySQL (local)
- **Frontend:** Bootstrap 5, Vanilla JS
- **Deployment:** Render
